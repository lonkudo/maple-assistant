# BOSS 追踪

`BOSS 追踪` 是一个与 Maple Assistant 完全独立的 Windows 桌面程序。它不截屏、
不发送游戏按键，也不依赖巡逻功能。

## 功能

- 一处设置所有频道共用的 BOSS 刷新间隔。
- 输入 `1` 到 `60` 的唯一整数频道号并添加频道。
- 每个频道拥有独立倒计时、可拖动剩余时间条、重置按钮和删除按钮。
- 每列最多显示 10 个频道；第 11 个频道开始新列，窗口随列数自动变宽，不使用滚动条。
- 三类输入框固定为 80 px，频道号显示区为 30 px；频道倒计时保持单行显示。
- 倒计时归零时播放 `sound/beep.mp3`，然后仅重置到期的频道。
- 提醒声后通过发布包内置的轻量 `comtypes` 直接调用 Windows 女性中文语音，
  将到期频道号播报两次，不再启动 PowerShell TTS。
- `BOSS 讨伐数量` 提供 `+1` 和 `-1`。
- 可添加任意自定义统计项目；点击名称字段外的窗口内容后变为文本，切换到其他应用不会误触发；点击文本可再次编辑；每项都有 `+1`、`-1` 和删除。
- 添加自定义统计项目时，窗口会随统计行数自动增高。
- 统计分析面板内的 `清空全部数据` 经确认后会清除全部频道和统计，但保留统一时间间隔。
- 所有频道、倒计时截止时间、统计和窗口位置自动保存到 `config.json`。

## 启动

第一次使用时，请按这个顺序操作：

1. 双击 `安装.bat`。
2. 等待安装完成；它会先从 Python 启动器、PATH、常见安装目录和 Windows 注册表
   寻找已有的 Python 3.10。找不到才会安装 Python 3.10，随后创建本地 `.venv`，
   并通过清华镜像安装依赖；镜像暂时不可用时会自动改用官方源。
3. 安装完成后会自动启动。以后只需双击 `启动BOSS追踪.bat`；正常运行时不会保留
   黑色命令窗口。

不要双击 `.py` 文件，也不要手动安装 Python 包。安装失败时保留黑色窗口并截图。

开发者也可在本目录运行：

```powershell
py -3.10 app.py
```

发布包同时内置轻量纯 Python 依赖，安装程序仍会将它安装到专用的本地环境，
确保每次启动一致。源码开发可运行 `py -3.10 -m pip install -r requirements.txt`。
更新版本时不要覆盖 `config.json`；官方发布 ZIP 不包含该文件。

## 发布

在本目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\release_now.ps1
```

脚本会运行测试、重建 `release/BossTracker`、创建新的时间戳 ZIP，并验证 ZIP
不包含用户的 `config.json`。
