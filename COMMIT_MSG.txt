fix: layer bands lose the +tolerance bottom slack (band = topmost - tol .. lowermost)

Adjacent floors' recorded Y bands overlapped at the BOTTOM edge: each band
extended tolerance BELOW its lowermost point, reaching into the layer below
(e.g. layer2 band .33..0.37 and layer3 band .33..0.37 both swallowed y=0.349).
The band is now (topmost point Y - tolerance, lowermost point Y): tolerance
is applied only ABOVE the topmost point (where climbs/drops arrive) and no
longer below the lowermost point, so a band does not reach into the layer
BELOW and the overlap windows shrink.

- movement_worker._layer_y_band / _layer_world_y_band: return
  (min - tolerance, max) instead of (min - tolerance, max + tolerance).
- patrol_control._layer_y_band / _layer_world_y_band: same rule.
- fixtures: fall/return/stale-world settle points moved from lowermost +
  tolerance to the lowermost value itself (0.82->0.80, 0.52->0.50, world
  -0.35->-0.40 / 0.1->0.0) - a real landing settles ON the platform, i.e.
  at the recorded lowermost Y, not below it.
