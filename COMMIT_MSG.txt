feat: remote lie API replaces the local pass; 测试api plays a video

Lie detection is now a call to the remote RoiTrack service, so the local Cutie
pass is gone: auto_lie_worker.py, lie_demo_player.py, auto_lie_overlay.py, the
whole target_tracker engine (realtime_fade_tracker, adaptive/roi/video players,
offline_bundle with the Cutie+ResNet weights, wheelhouse and python/vc_redist
installers, tracking_results), lie_video_tools' in-game replay and four test
modules.  target_tracker/ keeps only mouse_aim_controller.py (stdlib-only aim
controller) and install.ps1 stops installing torch/Cutie/VC++ for a tracker
($InstallLocalTracker = $false), so the CPU/CUDA package drops 379 MB -> 62 MB.

The 附加功能 row is now a single 测试api button.  It asks for a video file, plays
it at the API's 5 fps in its own focused, always-on-top window, uploads each
frame's lie ROI (372x248 BGR jpeg90 base64) and moves the real cursor onto the
answer - only inside the picture rectangle, never a click.  The 时长 box, the
密钥 button and the 测试api（抓屏）button are removed: the run is the measured
~30 s and the product key ships in autolie_api/key_secret.txt (LIE_PRODUCT_KEY
overrides it; with neither, the local mimic answers so the button always works).

Order, from the operator's own workflow: connect at once (probe -> chosen port
-> handshake), wait AWAIT_SECOND_WINDOW (3 s) while displaying but not feeding,
then feed for the rest of the run (~27 s of 30 s), then round_end and close
everything when the clip ends.  The wait is clamped to 8 s because 2.7.0 §4.1
kicks a session that goes 10 s without a valid frame.  A server-side reset
mid-round (observed once: WinError 10054 after 69 frames, no close frame) is
survived by opening a new session and restarting frame_id at 1, and a closed
socket is no longer mistaken for "no answer" - that bug cost two frames and a
1.5 s stall per reset.  The wait itself is justified by measurement: the test
clip's first 16 frames are one frozen image and the service answered
abandon_frame_hold for every one of them.

The measured lie-popup geometry moved out of the deleted worker into
lie_geometry.py, so autolie_api/intergration.py still derives the exact
(310, 118, 745, 496) ROI at 1366x768 (verified identical over five client
sizes).

Also in this tree: the RoiTrack client itself (autolie_api: endpoints, WS
transport, key store, per-run logs, local mimic), 自动重连 (login-page colour
gate, world/channel entry, 5-point calibration, temporary test button), the
JPG-only image policy (image_io.py), and MovementWorker's far "no progress"
endpoint bound.

Docs: README.md and ARCHITECTURE.md rewritten for the remote design - worker
list, frame flow, event chain, module inventory, test list, ignored paths and
the handoff state at 0390.  Tests: 757 collected, 9 known unrelated failures.

Release: MapleAssistant-CPU-v0390.zip / MapleAssistant-CUDA-v0390.zip.
